## Review Layout (spec-review-layout preset)

This project uses the spec-review-layout preset. It changes how `spec.md` is laid out for review. It does not change what the spec contains.

Before writing `spec.md`, read `.specify/presets/spec-review-layout/rules/spec-layout.md` and follow it for every section, including the Review Layout checks in its section 8. Where it conflicts with formatting guidance earlier in this command, follow the rules file. If the rules file does not exist, say that the preset is not installed correctly, then continue with the template structure alone.
